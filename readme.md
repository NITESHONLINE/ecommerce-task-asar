## For Contributors

To prevent code conflicts and keep our `main` branch secure, all contributors must follow this branching workflow:

### Workflow

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/NITESHONLINE/ecommerce-task-asar.git
   cd ecommerce-task-asar
   ```
2. **Create a Feature Branch:**
   _Never commit directly to the main branch._ Create a separate branch named after your feature:
   ```bash
   git checkout -b feat/your-feature-name
   ```
3. **Stage and Commit Changes:**
   ```bash
   git add .
   git commit -m "Add descriptive message about your changes"
   ```
4. **Push Your Branch to GitHub:**
   ```bash
   git push -u origin feat/your-feature-name
   ```
5. **Open a Pull Request (PR):**
   Go to GitHub and create a Pull Request from your branch to the `main` branch for review.
